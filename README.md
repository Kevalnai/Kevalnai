## Featured projects

### 🎟️ [Event Management Platform](https://github.com/Kevalnai/Event_Management) · *in progress*
Backend for an event ticketing platform: organizers create events, attendees buy tickets, and staff validate entry.
- **Stack:** Python, FastAPI, PostgreSQL, SQLAlchemy, JWT, bcrypt
- Modular domain design with separate **users, events, tickets, payments and scanners** modules, each split into routes → services → repositories
- JWT authentication with hashed passwords and a central security layer

### 📈 [Insightfolio](https://github.com/Kevalnai/Insigntfolio) · *in progress*
Investment portfolio tracker for stocks and crypto.
- **Stack:** Python, FastAPI, PostgreSQL, SQLAlchemy, React 19, Vite, Bootstrap
- Relational data model for users, assets, holdings (quantity and average buy price), transactions and price alerts
- Includes architecture diagram and project documentation

### 🧾 [Customer Invoice App](https://github.com/Kevalnai/CustomerInvoicesApp)
Customer and invoice management system for small businesses.
- **Stack:** C#, ASP.NET Core MVC, Entity Framework Core, SQL Server, Bootstrap
- Domain model for customers, invoices, line items and payment terms on EF Core 9 with SQL Server
- Customers use **soft delete** rather than hard delete, so a mis-click never destroys a record

### 🚚 [Marketplace Delivery System](https://github.com/Kevalnai/Delivery_system) · *team project*
Marketplace with third-party delivery and order tracking.
- **Stack:** Node.js, Express, MongoDB, Mongoose, EJS, Cloudinary
- Buyer and seller flows: product listings with image upload, cart, checkout and order tracking
- Session and JWT-based authentication, plus automated tests for auth, payments and products

### 💼 [Developer Portfolio](https://github.com/Kevalnai/Portfolio)
Personal portfolio site.
